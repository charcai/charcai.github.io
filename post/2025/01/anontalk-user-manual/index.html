AnonTalk 用户说明书: 面向对象程序设计(2024) 大作业

2025 / 01 / 04

本文档为北航软件工程课程面向对象程序设计(2024)大作业 AnonTalk 的用户说明书。

1. 项目运行环境

  • 浏览器: Google Chrome, Safari, Microsoft Edge 等现代内核浏览器
  • 测试服务器: macOS Sequoia
  • JDK版本: 22
  • IDE: IntelliJ IDEA Ultimate 2024.1
  • 数据库: MySQL 8.4.3，运行在 2C2G 的 Alibaba Cloud Linux 3 上；

注：涉及聊天、交友功能的网站若部署在云服务器生产环境需要额外进行备案审批，本项目暂未进行备案，仅供本地测试使用。

2. 功能介绍

欢迎使用 AnonTalk 匿名匹配对话平台！本手册将为您提供 AnonTalk 的使用说明。

1. 用户注册登陆

访问网站首页，未登陆状态下自动跳转到登陆界面。

点击“注册按钮，进入注册界面。

在注册界面填写自己的用户名、手机号、密码，点击“注册”按钮即可注册成功，进入网站首页。

请妥善保存您的用户名和密码，以免丢失。若有遗忘，请联系管理员进行密码重置。

2. 匿名匹配对话

在首页，点击“匹配”按钮，进入匹配。

若匹配队列用户过少，系统将提示 “匹配等待中”，请耐心等待。

当匹配成功后，系统将自动跳转到对话界面。

上方的消息框中显示了对话的历史消息。 在下方输入框中输入消息，点击 “发送” 按钮或按下 Enter 即可发送消息；

3. 个人设置

点击页面左侧的“个人设置”按钮，进入个人设置页面。

用户ID为系统自动生成，是用户的唯一标识，不可更改。

此界面可更改自己的用户名、性别、爱好等信息，以及手机号、密码等安全设置，点击 “保存” 按钮即可保存更改。

4. 交友广场

点击页面左侧的 “交友广场” 按钮，进入交友广场页面。

左侧显示了所有用户的帖子，右侧可以新建并发送一条帖子。

3. 异常处理

1. 用户名重复

若注册时用户名重复，系统将提示 “用户名已存在”，请更换用户名后重新注册。

2. 匹配等待中

若匹配队列用户过少，系统将提示 “匹配等待中”，请耐心等待。

3. 用户名或密码错误

请检查自己的用户名、密码是否有误，若有遗忘，请联系管理员进行密码重置。

4. 登陆/注册失败，请重试！

若登陆或注册失败，请检查网络连接，或联系管理员检查数据库连接、通信是否有误。

5. 其他异常

我们在浏览器的 Console、 IDE 的 终端 等地方输出了详细的异常信息，您可以查看这些信息来帮助我们更好地定位问题。
